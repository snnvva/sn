# Экзаменационный комплект: ИС туристической компании

Этот репозиторий содержит готовые материалы под задание:

1. Анализ системы и диаграммы
2. Логическая/физическая модель данных
3. Готовый SQL-скрипт PostgreSQL
4. Материалы для реализации пункта 3 в Windows Forms
5. Набор тест-кейсов

## Состав

- `sql/01_tour_agency_schema.sql`  
  Полный скрипт БД: таблицы, связи, ограничения, индексы, триггеры, view и тестовые данные.

- `docs/data-model.md`  
  Логическая модель + словарь данных.

- `docs/diagrams/use-case-tour-agency.md`  
  Mermaid use case диаграмма.

- `docs/diagrams/sequence-tour-selection.md`  
  Mermaid sequence диаграмма для сценария «Подбор тура».

- `docs/diagrams/er-tour-agency.md`  
  Mermaid ER-диаграмма.

- `docs/winforms/winforms-guide.md`  
  Пошаговая инструкция по реализации пункта 3 в WinForms (CRUD + фильтры).

- `tests/test-cases.md`  
  Тест-кейсы и шаблон протокола тестирования.

## Быстрый запуск БД в PostgreSQL

```bash
psql -U postgres -d postgres -f sql/01_tour_agency_schema.sql
```

После выполнения:

- схема: `tour_agency`
- основные данные для демонстрации уже заполнены
- для UI можно использовать `tour_agency.v_tour_catalog`

## Как показать Mermaid диаграммы

1. Открой любой `.md` файл из `docs/diagrams/`.
2. Если редактор поддерживает Mermaid (например, VS Code/Markdown preview), диаграмма визуализируется автоматически.

## Примечание по экзамену

По условию задания можно реализовывать в приложении только поддержку БД туров (пункт 3),  
а модель БД и диаграммы покрывают всю предметную область (заявки, статусы, бронирования и взаимодействие с организатором).
