# Тест-кейсы для функционала приложения (пункт 3)

## Условные обозначения

- **Предусловия**: что должно быть в БД до старта теста.
- **Шаги**: действия пользователя в WinForms.
- **ОР**: ожидаемый результат.

---

## TC-01: Просмотр списка туров

**Предусловия**: в таблице `tour` есть минимум 3 активных тура.  
**Шаги**:
1. Открыть главную форму.
2. Дождаться загрузки `DataGridView`.

**ОР**:
- Таблица отображает туры.
- Колонки заполнены корректными данными (название, страна, даты, цена, вместимость).

---

## TC-02: Добавление тура (валидные данные)

**Предусловия**: есть хотя бы 1 страна, менеджер, организатор.  
**Шаги**:
1. Нажать "Добавить тур".
2. Заполнить все обязательные поля корректно.
3. Нажать "Сохранить".

**ОР**:
- Отображается сообщение об успешном сохранении.
- Новый тур появляется в списке.
- В БД появляется запись в `tour`.

---

## TC-03: Добавление тура (невалидные даты)

**Шаги**:
1. Нажать "Добавить тур".
2. Установить `Дата окончания` раньше `Даты начала`.
3. Нажать "Сохранить".

**ОР**:
- Появляется сообщение валидации.
- Сохранение не выполняется.
- В БД новая запись не добавлена.

---

## TC-04: Добавление тура (невалидная вместимость)

**Шаги**:
1. Нажать "Добавить тур".
2. Указать `capacity = 0`.
3. Нажать "Сохранить".

**ОР**:
- Валидационное сообщение "Вместимость должна быть больше 0".
- Запись не сохраняется.

---

## TC-05: Редактирование тура

**Предусловия**: существует активный тур для изменения.  
**Шаги**:
1. Выбрать тур в таблице.
2. Нажать "Изменить".
3. Изменить цену и описание.
4. Сохранить.

**ОР**:
- Измененные поля отображаются в таблице.
- В БД значения обновлены (`UPDATE` выполнен).

---

## TC-06: Удаление тура (soft delete)

**Предусловия**: существует активный тур.  
**Шаги**:
1. Выбрать тур.
2. Нажать "Удалить".
3. Подтвердить действие.

**ОР**:
- Тур исчезает из списка активных.
- В БД у тура `is_active = false`.

---

## TC-07: Фильтрация по стране

**Предусловия**: есть туры минимум по двум разным странам.  
**Шаги**:
1. Выбрать конкретную страну в `cbCountryFilter`.
2. Нажать "Применить фильтр".

**ОР**:
- Отображаются только туры выбранной страны.

---

## TC-08: Фильтрация по диапазону дат

**Предусловия**: есть туры с разными датами начала/окончания.  
**Шаги**:
1. Включить фильтр по датам.
2. Указать `date_from` и `date_to`.
3. Нажать "Применить фильтр".

**ОР**:
- Отображаются только туры, попадающие в диапазон.

---

## TC-09: Комбинированная фильтрация (страна + даты)

**Шаги**:
1. Выбрать страну.
2. Указать диапазон дат.
3. Применить фильтр.

**ОР**:
- Результат удовлетворяет одновременно обоим условиям.

---

## TC-10: Сброс фильтров

**Шаги**:
1. Применить любой фильтр.
2. Нажать "Сбросить фильтр".

**ОР**:
- Возвращается полный список активных туров.
- Элементы фильтра в UI возвращены в значения по умолчанию.
